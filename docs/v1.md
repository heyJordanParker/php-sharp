# PHP# v1

v1 is feature-complete PHP#: the first version a team can build a real app in.

## What feature-complete means

- **Every rule of [the spec](spec.md) holds,** and every example in it passes `sharp/bin/spec`, so `sharp/baseline/spec` is empty.
- **The checker refuses nothing as "not supported yet".**
- **PHP# runs under every host a PHP app runs under:** php-fpm, the CLI, FrankenPHP and Laravel Octane, each lifetime meaning the same thing under each ([decision 78](decisions/078-hosts.md)).
- **It is released with both runtime images,** php-fpm's and FrankenPHP's.

## How v1 is measured

A validation app, an existing PHP app, measures it:

1. The app compiles and its tests pass on the PHP# engine.
2. Its files then move to PHP# one at a time, each coordinated with Jordan, and the app keeps working after each one.
